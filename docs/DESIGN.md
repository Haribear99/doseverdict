# DoseVerdict 디자인 규칙

웹 UI, 발표 덱, 상세기술서, 그림이 함께 따르는 규칙이다. 목표는 "규제 검토 문서" 톤이다. FDA 심사 문서나 학술지 표처럼 읽혀야 하고, AI 생성 템플릿처럼 보이면 안 된다.

## 레퍼런스

| 레퍼런스 | 가져온 것 |
|---|---|
| FDA Drug Trials Snapshots | 요약을 먼저 보이고 상세는 아래에 두는 2층 구조 (Findings 헤더 → 펼친 본문) |
| IBM Carbon Data Table | 선으로 구분하는 밀집 표, 헤더 아래 굵은 선 (KPI 줄, 덱 표) |
| Economist 차트 원칙, Tufte | 강조할 데이터만 색을 쓰고 나머지는 회색 (그림) |
| GOV.UK 경고 패턴 | 굵은 왼쪽 선과 짧은 문장 (기권 박스) |
| Linear UI 재설계 | 색 토큰을 최소로 유지 |
| EMA EPAR | 번호 매긴 섹션 위계 (기술서) |

## 토큰

단일 원천은 `app/ui/tokens.py`다. 같은 값을 따로 들고 있는 곳이 네 군데 더 있으므로, 값을 바꿀 때는 모두 함께 바꾼다.

- `.streamlit/config.toml`
- `docs/slides/deck.html`의 `:root`
- `docs/report.css`
- `evidence/make_figures.py`와 `app/eval/ledger.py`의 팔레트

| 이름 | 값 | 용도 |
|---|---|---|
| ink | `#1b2430` | 본문, 표 머리 아래 굵은 선 |
| muted | `#5b6472` | 보조 문장, 캡션 |
| paper | `#fbfaf7` | 배경 |
| soft | `#f2efe8` | 인용 배경, 비강조 막대 |
| line | `#dcd6ca` | 구분선 |
| accent | `#1f3a5f` | 강조 1색 (현재 노드, 주 버튼, 강조 데이터) |
| verified | `#2f7d4f` | 판정 상태: 검증 |
| held | `#b7791f` (글자 `#96610f`) | 판정 상태: 보류 |
| rejected | `#b4372f` | 판정 상태: 기각 |
| abstain | `#5a5f96` | 판정 상태: 기권 |

상태 4색은 판정 상태를 뜻할 때만 쓴다. 장식이나 구역 구분에는 쓰지 않는다. 그래서 다음은 상태색을 쓰지 않는다.

- 중증도(critical·high·medium·low): 무채색 위계(ink·muted, critical만 굵게)
- 에이전트 흐름 그래프의 완료 노드: soft 배경과 ink 글자
- 도구 호출 성공: 무색 (실패만 기각색)
- 수치 증감(+0.044, −10.4% 등): ink (좋고 나쁨을 색으로 칠하지 않는다)
- 0건인 상태 값: ink
- 인라인 코드: accent

## 타이포

- **본문:** Pretendard Variable을 쓰고, 없으면 Malgun Gothic으로 대체한다.
- **숫자:** `font-variant-numeric: tabular-nums`로 자릿수를 맞춘다.
- **인용 원문:** 프로토콜 span과 라벨 원문은 세리프로 쓴다. 영문은 Georgia, 한글은 Noto Serif KR이다. 사람이 쓴 원문과 시스템 문장을 서체로 구분하기 위해서다.
- **코드와 ID:** 모노스페이스로 쓴다.
- **라벨:** 대문자 변환(`text-transform: uppercase`)과 넓은 자간을 쓰지 않는다. 섹션 라벨은 굵은 본문 크기로 쓴다.

## 형태

- 구분은 선으로 한다. 그림자와 카드 나열은 쓰지 않는다.
- 블록 머리에는 1px ink 선을 두고, 행 사이는 1px line 선으로 나눈다.
- 모서리 라운드는 2px 이하로 한다.
- 배지는 2px 사각 라벨로 만든다. 알약형(`border-radius: 999px`)은 쓰지 않는다.

## 금지 목록

최종 검수 때 이 목록을 기준으로 확인한다.

- 그라디언트, 글로우, 컬러 그림자, glassmorphism
- 이모지 아이콘 (버튼, 제목, 타임라인, 성공·실패 표시)
- 위쪽이나 왼쪽에 색 테두리를 두른 카드 (예외: 기권 박스의 왼쪽 선은 GOV.UK 경고 패턴으로 허용)
- 같은 모양의 카드 3~4개를 한 줄로 늘어놓은 행
- 알약형 칩, 대문자 eyebrow 라벨
- 중앙 정렬 히어로
- 보라·인디고 계열 강조색 (abstain 보라는 상태 전용이다)
- 차트의 기본 팔레트 (matplotlib `C0` 등)

## 변경 규칙

- 디자인 작업에서는 문구와 수치를 바꾸지 않는다. 화면 수치는 `docs/시연영상_스크립트.md`의 대조표와 일치해야 한다.
- 화면을 바꾼 뒤에는 변경 전후 화면 텍스트를 비교해, 의도한 변경 외에는 차이가 없는지 확인한다.

## v2 (10-01 밤) — 첫인상 고도화

레퍼런스 리서치(웹 2건)에서 가져온 것과 버린 것이다.

| 레퍼런스 | 가져온 것 | 버린 것 |
|---|---|---|
| FDA Briefing Document 표지 | 기관·문서 유형·날짜의 정형 메타 줄 | 밋밋한 텍스트 표지 그대로는 쓰지 않는다(훅 숫자를 얹는다) |
| McKinsey action title, Duarte glance test | 장마다 결론 한 문장 제목 + 핵심 비주얼 1개 | 화살표·박스 과다, 단정 제목(근거 한정어를 유지) |
| Economist·FT·OWID 차트 | 강조 1계열만 accent, 나머지 muted, 점 옆 직접 라벨 | 브랜드 빨강·핑크 배경·다색 팔레트 |
| Nature 도판·통계 가이드 | 캡션에 오차막대 뜻(95% CI) 명시, 그림 안 글자 통일 | 7pt 규격(슬라이드에서 읽히지 않음) |
| CDS 설계(FDA CDS Criterion 4) | 결과 화면은 결론 → 근거 → 한계 순서, 기권은 오류 톤이 아님 | 규제 해당 여부 주장(설계 원칙으로만 인용) |

- 도표: `docs/figs/make_figs.py`가 numbers.md·tcr_240mg.json을 파싱해 만든다. 투명 배경, 기준선 위 라벨은 종이색 바탕. 덱용 판은 글자 1.45배.
- 표지: 기술서는 전면 표지(`docs/report_cover.html`, 위 40% 장식 사진·훅 문장 36pt·숫자 3칸 네이비). 생성 이미지는 표지에만 쓰고 "생성 이미지(장식)"로 표기한다.
- UI: 결과 화면 맨 위 결론 머리줄(32px). 문구는 데이터(abstain_reason·집계)에서 만든다.
